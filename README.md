# Spell Showdown Support

Public support and legal pages for the Spell Showdown game, published with GitHub Pages:

- Support: https://pugpugpugs.github.io/spellshowdown-support/support.html
- Privacy Policy: https://pugpugpugs.github.io/spellshowdown-support/privacy.html
- Contact Support / Report an Issue: https://github.com/pugpugpugs/spellshowdown-support/issues

This repository contains only these public pages. The Privacy Policy is the same text the app bundles; update both together.

Please don't post passwords, Apple ID credentials, payment information or other sensitive personal information in issues.
